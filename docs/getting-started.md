# 快速开始

本文面向使用者：如何安装 LocalDM、加载扩展、完成第一次下载。

## 安装

### 从 Release 安装（推荐）

1. 打开 [Releases](https://github.com/taiwanli/LocalDM/releases)。
2. 下载：
   - `LocalDM Setup x.y.z.exe`（安装到本机）
   - 或 `LocalDM-x.y.z-portable.exe`（免安装）
3. 运行安装包。若出现 SmartScreen，选择 **更多信息 → 仍要运行**。
4. 启动 **LocalDM**。

首次启动会显示引导：说明如何添加链接，以及扩展、代理、BT 等选项可稍后在设置中配置。

### 从源码运行

见仓库根目录 [README.md](../README.md#方式二源码运行)。

## 第一次下载

1. 点击工具栏 **添加**。
2. 粘贴直链（`.zip` / `.iso` / `.gguf` 等）或视频页 URL。
3. 确认保存目录后开始下载。
4. 任务出现在列表中，可查看进度、速度与状态。

### 工具栏说明

| 按钮 | 作用 |
|---|---|
| 添加 | 新建下载任务 |
| 暂停 / 继续 | 操作当前选中任务 |
| 全部暂停 / 全部恢复 | 批量操作可暂停/可恢复任务 |
| 删除选中 | 移除当前选中任务 |
| 清空已完成 / 清空失败 | 按状态清理列表 |
| 关于 / 设置 | 版本信息与偏好配置 |

无可操作对象时，对应按钮会自动禁用。

## 浏览器扩展（推荐）

扩展用于：右键把链接送入桌面端、嗅探页面资源、接管浏览器下载并提示。

### 加载步骤

1. 保持 LocalDM 桌面端运行。
2. 查看扩展目录：
   - 安装版 **关于** 页会显示路径，例如 `C:\Program Files\LocalDM\resources\extension`
   - 源码开发：仓库内 `extension/` 目录
3. Chrome：`chrome://extensions` → 打开 **开发者模式** → **加载已解压的扩展程序** → 选择上述目录。  
   Edge：`edge://extensions` → **开发人员模式** → 同样操作。
4. 点击扩展图标，确认显示 **桌面端已连接**。

### 常用扩展能力

| 操作 | 说明 |
|---|---|
| 右键「下载此链接」 | 将直链送入 LocalDM |
| 右键「下载此视频」 | 视频站点页面交给桌面端解析 |
| 嗅探本页资源 | 将页面检测到的媒体批量送入 |
| 下载接管 | 浏览器开始下载时可取消并转到 LocalDM |

> 视频站点（如抖音、YouTube 等）请对**页面 URL** 使用「下载此视频」，不要依赖弹窗里偶发的分片列表。

## 可选工具

| 能力 | 需要 |
|---|---|
| 普通多线程下载 | 无需额外工具 |
| 视频站点 / 部分流媒体 | `yt-dlp`（+ 合并时 `ffmpeg`） |
| HLS 合并 | `ffmpeg` |
| BT / 磁力 | `aria2c`，并在设置中启用 BT |

Release 安装包通常已附带上述工具。源码用户请自行放到 `resources/bin/`，或在设置中指定路径。

## 下载策略

当前版本策略固定：

- **Range 多线程** + **限流自适应**
- 遇到限流/鉴权类响应（401/403/429/567 等）会降低有效连接并稍后重试
- 设置页可调连接数、并发数；可关闭「限流时自动降并发」

## 数据保存位置

运行数据在系统应用数据目录（Electron `userData`）下的 `LocalDM/`：

| 文件 | 内容 |
|---|---|
| `settings.json` | 设置 |
| `tasks-state.json` | 任务列表 |
| `logs/app.log` | 运行日志 |
| `api-token` | 本地 API 密钥（保密） |

**关于** 页可快速打开日志或复制路径。

## 常见问题

### 扩展显示未连接

1. 确认桌面端已启动。
2. 在扩展弹窗中核对 API 端口（默认 `37280`），需与桌面设置一致。
3. 修改后重新加载扩展（扩展页 → 刷新图标）。

### 视频下载失败

- 确认 `yt-dlp` 路径可用（关于页/设置中可查看工具状态）。
- 更新 yt-dlp 到较新版本。
- 部分站点需要登录 Cookie：在设置中选择 `cookieBrowser`（如 chrome）。

### 磁力任务提示未启用

到 **设置 → 系统/进阶** 打开「启用 BT/磁力下载」，并确认 `aria2c` 存在。

### SmartScreen 拦截

开源个人构建未做商业签名时可能出现提示。确认下载来源为本仓库 Releases 后，选择「更多信息 → 仍要运行」。
